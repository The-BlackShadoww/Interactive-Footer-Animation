# Physics footer

A footer whose skill tags fall into place with real physics when you scroll down to it. Grab them with the mouse and throw them around. Matter.js runs the physics, GSAP ScrollTrigger starts it on scroll, and Lenis smooths the scroll.

**Live:** [interactive-footer-animation.vercel.app](https://interactive-footer-animation.vercel.app)

**Stack:** HTML, CSS, vanilla JavaScript, Matter.js, GSAP ScrollTrigger, Lenis

**Run it:** `npx serve .` and open the printed URL.

A practice piece for physics-based UI.
